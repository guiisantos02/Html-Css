Meu Portfólio

Projeto Wave Cast

Uma aplicação web de streaming de música inspirada no Spotify, desenvolvida para proporcionar uma experiência imersiva de reprodução de áudio. O Wave Cast oferece uma interface moderna e intuitiva que permite aos usuários navegar, descobrir e reproduzir suas músicas favoritas..

Projeto Culturama

Uma plataforma web responsiva dedicada à divulgação e descoberta de eventos culturais. O site apresenta uma interface moderna e intuitiva que permite aos usuários explorar diversos tipos de eventos como shows, teatro, festivais, cinema, arte, fotografia, tecnologia e design..
